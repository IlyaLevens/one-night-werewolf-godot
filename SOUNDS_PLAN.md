# Звуки для следующего обновления

План: общий короткий звук при начале каждого ночного этапа роли, однократно.
Если карта роли находится в центре, её этап и звук остаются такими же.
Файлы пока не подключены. Прикрепите их отдельными файлами или одним ZIP.

Желательно: WAV или MP3, 2–4 секунды, без фоновой музыки и длинной тишины,
с мягким окончанием, похожей громкостью и без резких пугающих пиков.
Не обязательно искать именно эти эффекты — это художественные ориентиры.

| Файл | Роль | Звуковой образ |
| --- | --- | --- |
| werewolf.mp3 | Оборотень | Один далёкий волчий вой, тихий лесной ветер |
| minion.mp3 | Миньон / приспешник | Скрип двери и осторожные шаги |
| mason.mp3 | Масон | Два приглушённых удара молотка по камню |
| seer.mp3 | Провидица | Звон стеклянной чаши с коротким воздушным затуханием |
| robber.mp3 | Вор | Тихий звон ключей, шорох ткани |
| troublemaker.mp3 | Смутьян | Быстрый двойной шелест карт с лёгким свистом движения |
| drunk.mp3 | Пьяница | Позвякивание бутылки и короткий плеск жидкости |
| insomniac.mp3 | Бессонница | Скрип кровати и тихий вздох или короткий вдох |

У охотника, кожевника и мирного жителя нет отдельных ночных этапов.
Поэтому эти дополнительные звуки пригодятся только для публичной развязки:

| Файл | Событие | Звуковой образ |
| --- | --- | --- |
| hunter.mp3 | Выстрел погибшего охотника | Взведение курка и один приглушённый выстрел |
| tanner.mp3 | Победа кожевника | Скрип натягиваемой кожи и короткий глухой удар |
| villager.mp3 | Победа деревни | Один тёплый колокольный звон |

Дополнительно для окружения можно приложить циклы по 30–60 секунд:
fireplace.mp3 — тихий камин для лобби; night_wind.mp3 — ночной ветер и лес;
morning.mp3 — лёгкий ветер и редкие утренние птицы.
Для голосования подойдёт отдельный короткий village_bell.mp3 — далёкий колокол.

При будущей реализации музыка, окружающий фон и сигналы должны иметь отдельные
регуляторы громкости. Уже прошедшие сигналы не нужно повторять при обновлении
страницы, переподключении или каждом опросе сервера. На новом этапе роли новый
сигнал слышен всем независимо от карты конкретного игрока.
