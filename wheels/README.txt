These wheels are distributed with their original licenses inside each .whl archive.
They are Python-only wheels (none-any), suitable for Python 3.9+ on Windows,
including 32-bit and 64-bit Python. No compiler is required on the user's computer.

Packages were obtained from https://pypi.org/simple/ at the versions specified
in requirements-offline.txt. SHA-256 hashes in that file are checked on installation.
MarkupSafe was built from the unchanged official MarkupSafe 3.0.4 source archive,
using its supported fallback to the Python implementation when the optional C
extension cannot be compiled (CC=false). No third-party source files were edited.
This avoids requiring a platform-specific binary or a compiler on Windows.
Source: https://pypi.org/project/MarkupSafe/3.0.4/
Source archive SHA-256: 2e9ad7dd851bf45fab9f75cbff4cb493fee9979e8d8c7c9c3ee119022518edd6

To install, use the game's install_dependencies.py inside its virtual environment.
Keep this folder with the game when copying it to another computer.
