ОБЩАЯ МУЗЫКА ЛОББИ

Положите сюда свои MP3: например, 01 - Ночь.mp3, 02 - Деревня.mp3.
Папка music должна находиться рядом с app.py на компьютере с сервером.
Русские имена и пробелы поддерживаются. Вложенные папки не сканируются.

Войдите в лобби. Создатель выбирает трек и нажимает «Включить всем».
Его пауза и переключение треков передаются всем игрокам этого лобби.
Каждый друг один раз нажимает «Разрешить музыку» для звука в своём браузере.
Подключившийся позже слушатель присоединяется к текущему моменту трека.

«Выключить у себя» и громкость действуют только на ваше устройство.
Они сохраняются в браузере, общий запуск или смена трека их не сбрасывают.
После обновления страницы снова разрешите звук. При выходе из лобби музыка
останавливается у вас. Создатель также может выключить свой звук отдельно.

Треки идут по алфавиту и повторяются по кругу по общему серверному таймеру.
Если создатель закрыл вкладку, музыка у остальных продолжится.
Окно Python-сервера должно оставаться открытым. При передаче прав создателя
новый создатель получает управление музыкой. У каждого лобби свой плеер.
Возможна небольшая задержка между устройствами (обновление примерно раз в секунду).

После добавления файлов нажмите ↻, перезапуск сервера не нужен.
Друзьям не требуется копировать music или скачивать игру: музыка идёт с сервера.
Музыкальные записи в архив не включены — добавьте свои.

Также поддерживаются M4A, MP4, OGG, WAV, WEBM при поддержке кодека браузером.
Из MP4 проигрывается только звук (рекомендуется AAC). MP3 — основной формат.
Если длительность не распознана (например, WEBM), следующий трек включает создатель.
