# One Night Werewolf — Godot

Полный проект находится в [One_Night_Werewolf_Godot.zip](One_Night_Werewolf_Godot.zip). Скачайте архив кнопкой Download raw file, распакуйте целиком через Проводник и импортируйте файл `project.godot` из папки `One_Night_Werewolf_Godot` в Godot.

# Одна ночь — самостоятельный проект Godot

Готовый проект на GDScript для **Godot 4.6 Standard**, проверен движком 4.6.3. Python, Node.js, браузер и .NET для игры не нужны. В архиве исходники, сцена, графика, шрифт, тесты и запуск трёх окон. Исполняемый файл Godot в архив не включён.

## Открыть игру

1. Распакуйте весь архив в обычную папку (не запускайте из ZIP).
2. Откройте Godot 4.6 Standard. В менеджере проектов нажмите **Import / Импорт**, выберите `project.godot` из распакованной папки.
3. Откройте проект, дождитесь импорта ресурсов и нажмите **F5**.
4. Введите имя и нажмите «Создать лобби», либо введите IP создателя и нажмите «Подключиться».

## Проверить одному в трёх окнах на Windows

Закройте предыдущие запуски, чтобы порт 27888 был свободен.

Перетащите **файл программы Godot (.exe)** на `test_3_players.bat`. Скрипт импортирует ресурсы и запускает три самостоятельных окна: Host, Player2, Player3. Либо выполните в командной строке:

```bat
test_3_players.bat "C:\Godot\Godot_v4.6.3-stable_win64.exe"
```

Укажите настоящий путь к вашему Godot. Скрипт использует адрес `127.0.0.1`, порт `27888`. Если Godot есть в PATH, достаточно двойного клика по BAT.

На Linux:

```bash
bash test_3_players.sh /путь/к/godot
```

На macOS передайте путь к бинарному файлу внутри приложения, например `/Applications/Godot.app/Contents/MacOS/Godot`. Скрипты Windows/macOS здесь не запускались; сетевой тест проведён на Linux.

В каждом окне нажмите «Я готов», затем у Host — «Начать раунд». Подтвердите ознакомление с ролью в каждом окне. Во время активной ночной роли выберите карты и подтвердите действие. Дождитесь таймера: этап не заканчивается раньше даже после хода, чтобы время не раскрывало состав игроков. После обсуждения проголосуйте во всех окнах. Проверьте результаты и таблицу очков, затем начните следующий раунд.

## Играть втроём на разных компьютерах в одной сети

1. На каждом компьютере распакуйте одинаковый проект и откройте его в Godot.
2. Все компьютеры подключите к одной локальной сети. Один игрок нажимает «Создать лобби». Создатель тоже играет: всего нужны три экземпляра, не четыре.
3. На Windows у создателя выполните `ipconfig`, найдите IPv4 активного Wi-Fi/Ethernet, например `192.168.1.42`.
4. Остальные вводят **этот адрес**, одинаковый порт `27888`, разные имена и нажимают «Подключиться». `127.0.0.1` подходит только для окон на одном компьютере.
5. Если Windows запросит доступ Godot к сети, разрешите доступ для своей частной сети. Для подключения используется **UDP 27888**. Гостевой Wi-Fi может изолировать устройства друг от друга.
6. Все нажимают «Я готов», создатель запускает раунд.

Для игры через интернет потребуется доступность UDP-порта создателя (проброс порта на роутере при публичном IP) или общая виртуальная LAN. Обычная HTTP-ссылка Pinggy не подходит к этому сетевому протоколу. Интернет-подключение и конкретные провайдеры туннелей не проверялись.

## Что перенесено

- 3–10 игроков, три карты центра, автоматическая или ручная колода, настройка таймеров.
- Все 11 ролей исходной игры; ночные действия по начальным ролям, победа по итоговым картам.
- Авторитетный сервер у создателя, проверка целей и фаз, персональные сведения, общий чат.
- Оборотни, миньон, масоны, провидица, грабитель, смутьян, пьяница, бессонница, охотник, кожевник, мирный.
- Подсчёт казни и ничьих, жертва охотника, большие красные кресты на погибших карточках.
- За победу: каждому мирному +1; каждому оборотню и миньону +2; кожевнику +3. Начисление один раз в конце раунда. Очки остаются между раундами этого лобби.
- Анимированные полосы таблицы, пропорциональные очкам; таблица доступна кнопкой во время игры и показана в лобби/результатах.
- Полноэкранное уведомление перед вашим ночным этапом, раскрытием и голосованием; обычные окна подтверждения.
- Анимированное небо, Луна/Солнце, облака, звёзды, деревня и плавные переходы между фазами. Анимацию окружения можно отключить.
- Неизменяемый журнал личных наблюдений: информация сохраняет смысл на момент действия, а не раскрывает последующие обмены.
- Восстановление отключившегося клиента по ключу, пока создатель продолжает держать сервер. Кнопка копирует личный ключ; сохраните его заранее. Для восстановления используйте тот же IP/порт и вставьте ключ. Не делитесь ключом с другими игроками.

У начальной карты на столе всегда показана ваша **начальная роль**. Изменения и наблюдения смотрите в личных сведениях ниже. Все итоговые карты раскрываются только в результатах.

## Музыка и сигналы ролей

В исходном архиве нет пригодных музыкальных записей. Здесь предусмотрено воспроизведение, но реальные треки и сигналы **не включены**.

- Музыка: положите `.ogg`, `.wav` или `.mp3` в `audio/music/`.
- Сигналы: `audio/roles/werewolf.ogg`, `minion.ogg`, `mason.ogg`, `seer.ogg`, `robber.ogg`, `troublemaker.ogg`, `drunk.ogg`, `insomniac.ogg`. Вместо OGG можно WAV или MP3. Лучше короткие 2–5-секундные записи.
- После добавления откройте редактор, дождитесь импорта, перезапустите игру. Одинаковые файлы должны быть на всех компьютерах.
- Сигнал начала этапа слышат **все**, даже если роль лежит только в центре. У охотника, кожевника и мирного нет своего ночного этапа.
- Создатель выбирает трек и запускает его у всех через «Звук / музыка». Положение музыки синхронизируется; файлы по сети не передаются. Громкость каждый регулирует отдельно.

## Отличия от браузерной версии

Это самостоятельный нативный клиент и сервер Godot. Подключение по IP/UDP вместо кода комнаты на Python-сервере. Совместимость с браузерными клиентами не предусмотрена. Создатель — доверенная сторона, его процесс хранит полное состояние. При закрытии создателя лобби и очки теряются; передачи сервера другому игроку и сохранения кампании на диск нет. Сборка предназначена для настольного запуска; мобильный и веб-экспорт не настроены.

## Проверки разработчика

В Godot 4.6.3 на Linux прошли импорт и запуск, 17 проверок правил, 500 сравнений подсчёта результатов с исходной Python-функцией, сетевой сценарий из трёх отдельных процессов на два раунда с одинаковыми результатами и очками. Проверялись отсутствие чужих ролей в публичном списке, охотник, кожевник, защита от повторных действий и начислений, обмен грабителя и обязательный ход пьяницы. Визуальная ручная проверка окон и реальная LAN между компьютерами в этой среде не проводились.

```bash
godot --headless --editor --path . --import --quit
godot --headless --path . --script tests/rules_test.gd
godot --headless --path . --script tests/parity_test.gd
python3 tests/network_test.py godot
```

Python нужен только для последнего вспомогательного теста. Фикстуры `tests/parity.json` получены из исходной функции `resolve_result` с фиксированным seed 1917. Для игрового запуска не используйте флаг `--test-bot`: он включает автопрохождение с сокращёнными таймерами на тестовом сервере.

## Структура

`scenes/main.tscn` — главная сцена; `scripts/main.gd` — интерфейс; `network.gd` — ENet/RPC; `rules.gd` — серверные правила; `roles.gd` — каталог ролей; `atmosphere.gd` — окружение; `card.gd` — карты; `scores.gd` — диаграмма; `audio.gd` — звуковой проигрыватель. Иконки перенесены из предоставленного проекта. Лицензия шрифта лежит в `assets/fonts/LICENSE.txt`.

Для получения отдельного EXE: в Godot установите шаблоны экспорта той же версии, откройте Project → Export, добавьте Windows Desktop и выполните Export Project. Это отдельный шаг; данный архив является проектом, а не собранным установщиком.
