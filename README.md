# One Night Werewolf — игра с друзьями на Python

Готовая неофициальная реализация «Оборотней на одну ночь»: один человек запускает
Python-сервер, остальные открывают игру в браузере. Можно играть с телефонов и ПК,
в одной сети или через интернет. Python нужен только на компьютере с сервером.

**3–10 игроков · 11 типов ролей · интерфейс на русском · автоматический ведущий.**

## 1. Быстрый запуск в Windows

1. Установите **Python 3.9 или новее** с https://www.python.org/downloads/.
   Если установщик предлагает `Add python.exe to PATH`, включите эту опцию.
2. **Распакуйте архив целиком** в отдельную папку. Не запускайте файлы внутри ZIP.
3. Откройте папку `one_night_werewolf` и дважды нажмите **`start_windows.bat`**.
4. При первом запуске будут созданы `.venv` и установлены Flask, Waitress и модуль чтения длительности музыки.
   Зависимости устанавливаются из папки `wheels` внутри архива: интернет для этого не нужен.
5. Когда появится `На этом ПК: http://127.0.0.1:8000`, откройте этот адрес в браузере.
6. Введите имя и нажмите **«Создать лобби»**. Код из шести символов появится вверху.
7. Подключите друзей одним из способов ниже. Нужно минимум три игрока.

**Окно сервера должно оставаться открытым всю игру.** Остановка — `Ctrl+C`.
После установки зависимостей для игры по локальной сети интернет не требуется.
Сервер запускается на Waitress, а не на отладочном сервере Flask.

### Если нужен ручной запуск

Откройте PowerShell в папке проекта:

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe install_dependencies.py
.\.venv\Scripts\python.exe app.py
```

Активация окружения не нужна: команды обращаются к его Python напрямую.
Если команды `py` нет, замените первую команду на `python -m venv .venv`.

### Linux / macOS

```bash
sh start.sh
```

Или вручную:

```bash
python3 -m venv .venv
.venv/bin/python install_dependencies.py
.venv/bin/python app.py
```

## 2. Подключение по одной Wi-Fi сети

1. Сервер и устройства друзей должны быть в одной локальной сети.
   ПК может быть подключён к роутеру кабелем, телефоны — по Wi-Fi.
2. Сервер старается вывести строку `В локальной сети: http://192.168...:8000`.
   Используйте адрес вашего домашнего сетевого адаптера.
3. Если адрес не появился или их несколько, откройте командную строку Windows,
   выполните `ipconfig` и найдите **IPv4-адрес** действующего Wi-Fi/Ethernet адаптера.
   Например, при адресе `192.168.1.42` друзья открывают **`http://192.168.1.42:8000`**.
   Числа в примере замените своими.
4. Если брандмауэр Windows спросит разрешение для Python, разрешите доступ
   в вашей **частной сети**. Полностью отключать брандмауэр не нужно.
5. Друзья вводят свои имена и код лобби, затем нажимают **«Войти»**.

**Важно:** адрес `localhost` / `127.0.0.1` у каждого указывает на его собственное
устройство. Друзьям нужен адрес вашего ПК. Если вы открыли игру на сервере через
`127.0.0.1`, кнопка приглашения скопирует именно этот локальный адрес. Для правильной
ссылки сначала откройте игру через LAN-адрес вашего ПК или через интернет-ссылку.

Гостевая Wi-Fi сеть или настройка «изоляция клиентов» у роутера могут блокировать
соединение устройств друг с другом. Телефон с мобильным интернетом не находится
в вашей локальной сети — для него используйте следующий способ.

## 3. Подключение друзей из разных домов

Для пробной игры удобен **Cloudflare Quick Tunnel**: он выдаёт временный HTTPS-адрес
для запущенного локального сервера. Проброс портов на роутере не требуется.
Аккаунт и собственный домен для Quick Tunnel не нужны.

### Пошагово для Windows

1. Запустите игру, как описано выше, и оставьте окно сервера открытым.
2. Откройте официальную страницу загрузок:
   https://developers.cloudflare.com/tunnel/downloads/.
3. В разделе **Windows** скачайте **Executable → 64-bit**, если у вас 64-битная Windows.
   Переименуйте скачанный файл в `cloudflared.exe` и поместите рядом с `app.py`.
   Утилита не входит в архив игры.
4. Откройте **второе** окно PowerShell в этой папке и выполните:

   ```powershell
   .\cloudflared.exe tunnel --url http://127.0.0.1:8000
   ```

5. Найдите выведенную программой ссылку вида `https://...trycloudflare.com`.
   Это настоящий публичный адрес вашего сервера, а не `localhost`.
6. **Сами тоже откройте игру по этой HTTPS-ссылке.** Создайте лобби именно там.
   Сессии на локальном адресе и публичном адресе разные. Если лобби уже создано
   локально, можно перенести вход через личный ключ восстановления.
7. Нажмите **«Пригласить друзей»** и отправьте полученную ссылку друзьям.
   В ней уже будет код лобби; каждому останется ввести имя и нажать «Войти».
8. Не закрывайте ни окно игры, ни окно `cloudflared`, пока идёт партия.

Для macOS/Linux после установки `cloudflared` команда та же, но без ` .\ `:

```bash
cloudflared tunnel --url http://127.0.0.1:8000
```

Quick Tunnel предназначен для тестирования: адрес меняется при перезапуске,
доступность не гарантируется. В некоторых сетях сервис может быть недоступен.
Делитесь ссылкой и кодом с вашей компанией: любой, кто их знает, может войти
в незапущенное лобби, пока там есть места. Сам сервер не публикует список комнат.

Официальная инструкция: https://developers.cloudflare.com/tunnel/get-started/quick-tunnels/.

### Если нужен постоянный адрес

Проект можно разместить на собственном сервере или контейнерном хостинге:

```bash
docker build -t one-night-werewolf .
docker run --rm -p 8000:8000 one-night-werewolf
```

Либо установить зависимости и задать команду запуска `python app.py`.
Переменная окружения `PORT` поддерживается. Перед Waitress для публичного сервера
настройте HTTPS на хостинге или через обратный прокси.

Запускайте **ровно один процесс / одну реплику** приложения: лобби находятся в памяти.
Несколько потоков внутри Waitress уже включены. Несколько отдельных процессов
получат разные наборы комнат. База данных для этой версии не нужна.

## 4. Как провести первую партию

1. Дождитесь всех игроков. При 3–5 участниках автоподбор даёт простой набор:
   два оборотня, провидица, вор, смутьян и мирные жители.
2. Создатель может изменить длительность этапов или вручную выбрать колоду.
   Общее число карт — **игроки + 3**. Масоны добавляются парой.
3. Каждый нажимает **«Я готов играть»**, затем создатель — **«Начать игру»**.
   При изменении настроек или состава игроков готовность сбрасывается.
4. Каждый открывает **личную карту**, запоминает роль и нажимает подтверждение.
   Сервер также начнёт ночь по истечении 90 секунд.
5. Ваша очередь появится автоматически. Нажмите на подсвеченные карты на круглом
   столе и подтвердите действие. Просмотр переворачивает карты, обмен показывает
   перемещение. Результат также сохраняется в разделе **«Что вы знаете»** своей личной карты. Кнопка «Открыть» скрывает
   сведения от случайного взгляда, но не меняет игровое состояние.
6. После ночи обсудите события в чате или голосом. Встроенного голосового чата нет:
   при удалённой игре можно параллельно использовать привычный групповой звонок.
7. Голосование начнётся по таймеру или по кнопке создателя. Каждый выбирает
   **другого** игрока и подтверждает решение. После подтверждения голос окончательный.
8. После всех голосов или таймера сервер раскрывает карты, голоса и историю ночи.
   Создатель нажимает **«Ещё одну ночь»**, все снова отмечают готовность.

### Общая музыка лобби из папки `music`

1. На компьютере с сервером положите свои **MP3-файлы** в папку `music` рядом с `app.py`.
   Например: `one_night_werewolf/music/01 - Ночная деревня.mp3`.
2. Создайте лобби. На панели **«Музыка лобби»** выберите трек и нажмите
   **«Включить всем»**. Только создатель лобби управляет общим воспроизведением,
   паузой и сменой трека. Для добавленных файлов есть кнопка обновления `↻`.
3. Друзья входят в лобби и один раз нажимают **«Разрешить музыку»** у себя.
   После этого запуск, пауза и смена трека создателем передаются всем слушателям.
   Если музыка уже играет, новый слушатель подключается к текущему моменту трека.
4. **«Выключить у себя»** отключает только ваш звук. Громкость тоже личная.
   Эти настройки сохраняются в браузере; смена трека или общий запуск их не сбрасывают.
   Создатель также может отключить свой звук, продолжая управлять музыкой для друзей.
5. Треки идут по алфавиту и повторяются по кругу. Сервер читает длительность файлов
   и отсчитывает общую позицию; переключение продолжает работать, даже если вкладка
   создателя закрыта. Сам Python-сервер должен оставаться запущенным.

У каждого лобби свой плеер. Музыка не перезапускается при смене игровых фаз,
просмотре карт или начале нового раунда. После выхода из лобби воспроизведение
на этом устройстве останавливается. При передаче прав создателя управление
плеером тоже переходит новому создателю, текущий трек сохраняется.

После обновления страницы снова нажмите **«Разрешить музыку»**: браузер может
требовать действие пользователя для звука. Если включение заблокировано,
плеер покажет подсказку. Во время долгой потери связи звук приостанавливается;
после восстановления плеер догоняет общую позицию. Команды передаются примерно
раз в секунду, поэтому небольшая задержка между устройствами возможна.
На телефоне браузер или система могут приостанавливать звук в фоновой вкладке.

Основной формат — **MP3**. Дополнительно принимаются `.m4a`, `.mp4`, `.ogg`, `.wav`
и `.webm`, если аудиокодек поддерживает браузер. В MP4 воспроизводится только
звук; для него рекомендуется AAC. Если длительность файла не удаётся определить
(например, для WEBM), после его окончания создатель переключает трек вручную.
Записи в архив не включены — добавьте свои. Русские имена, пробелы и `.MP3`
поддерживаются. Вложенные папки не сканируются. Перезапуск после добавления файлов
не нужен, MP3 передаются с вашего сервера — друзьям копировать музыку не требуется.

### Интерактивный стол

Открытые карты команды оборотней (оборотень и приспешник) — графитово-чёрные,
команды деревни — приглушённые бордово-красные. Кожевник играет за себя, поэтому
его карта бронзовая. Название команды также написано на карте. Все закрытые
карты имеют одинаковые рубашки: цвет команды появляется только при разрешённом
просмотре. В финале цвет соответствует конечной роли после всех обменов.

Иконки всех 11 ролей заменены предоставленными PNG с прозрачным фоном.
В интерфейсе чёрные силуэты отображаются светлыми для контраста;
исходные изображения в `static/icons` сохранены без изменения.


- Игроки и карты располагаются по кругу; ваше место всегда внизу.
  Три карты центра находятся посередине. На узком экране стол прокручивается
  по горизонтали, чтобы карты оставались достаточно крупными для нажатия.
- В начале раунда нажмите на свою карту: она перевернётся. Повторное нажатие
  закроет её. Начальная роль также доступна в личной панели.
- **Провидица:** выберите одного другого игрока или две карты центра, затем
  нажмите «Посмотреть карты». Переход между игроком и центром заменяет выбор.
- **Одинокий оборотень:** выберите одну карту центра и подтвердите просмотр.
- **Вор:** выберите другого игрока и нажмите «Поменять карты». После анимации
  открывается только полученная вами карта.
- **Смутьян:** выберите двух других игроков и подтвердите обмен. Обе карты
  перемещаются закрытыми. Свою карту выбирать нельзя.
- **Пьяница:** выберите одну карту центра и подтвердите обмен со своей картой.
  Полученная роль остаётся неизвестной.
- **Оборотни, приспешник, масоны и бессонница:** разрешённая информация
  автоматически отображается на столе в соответствующий ночной этап.
- Другие игроки не видят ваших ночных просмотров, выбранных целей или анимаций.
  Когда этап заканчивается, карты снова закрываются; снимок наблюдения остаётся
  в ваших личных заметках. Более поздние обмены этот снимок не обновляют.
- **Голосование:** нажмите на карту подозреваемого, затем подтвердите голос.
- В финале все конечные роли открываются. Нажмите на открытую карту, чтобы
  рассмотреть её крупнее и прочитать описание роли.

Управление — нажатия мышью, касания либо клавиши Tab / Enter; перетаскивание
не требуется. После выбора действие выполняется только по кнопке подтверждения.
Настройка уменьшения анимаций в системе учитывается.

## 5. Роли и порядок ночи

| Порядок | Роль | Действие |
|---|---|---|
| 1 | Оборотень ×2 | Видит других начальных оборотней. Одиночка может посмотреть одну карту центра. |
| 2 | Приспешник | Видит начальных оборотней; оборотни не узнают приспешника. |
| 3 | Масон ×2 | Видит второго начального масона либо узнаёт, что тот в центре. |
| 4 | Провидица | Смотрит одного другого игрока или две разные карты центра. |
| 5 | Вор | Меняет свою карту с другим игроком и смотрит полученную карту. |
| 6 | Смутьян | Меняет карты двух других игроков, не раскрывая их. |
| 7 | Пьяница | Меняет свою карту с одной картой центра, не смотрит результат. |
| 8 | Бессонница | Автоматически узнаёт свою карту после всех обменов. |
| — | Мирный житель ×3 | Не просыпается. Участвует в обсуждении и голосовании. |
| — | Охотник | При гибели забирает с собой игрока, против которого голосовал. |
| — | Кожевник | Отдельная команда. Хочет погибнуть в конце раунда. |

Всего доступны 15 карт, 11 типов ролей. **Доппельгангер и роли дополнений
в этой версии не реализованы.** Нужные карты выбираются из доступного набора.

Ночью действует **начальная** роль. После обмена вор не выполняет способность
полученной роли. Днём нельзя посмотреть свою новую карту; интерфейс хранит
начальную роль и уже полученные сведения. Победа определяется **конечной** картой.

## 6. Голосование и победа

- Казнят игрока с максимальным количеством голосов, если их хотя бы два.
  При равенстве максимума казнят всех лидеров. Если максимум 0 или 1, казни нет.
- Затем применяется способность погибшего охотника.
- Погиб хотя бы один конечный оборотень — побеждает деревня.
- Оборотни есть у игроков, но никто из них не погиб — побеждает команда оборотней,
  включая приспешника, даже если сам приспешник погиб. Исключение — победа кожевника.
- Конечных оборотней у игроков нет: деревня выигрывает, если никто не погиб
  либо погиб приспешник. Если погиб только мирный игрок и приспешника нет,
  никто не побеждает.
- Без оборотней приспешник побеждает, если сам выжил, а кто-то другой погиб;
  победа кожевника перекрывает этот исход.
- Погиб кожевник — побеждает кожевник. Если вместе с ним погиб оборотень,
  деревня тоже выигрывает. Если оборотень не погиб, выигрывает только кожевник.

### Онлайн-правила для таймеров и отключений

- Все этапы выбранных ночных ролей имеют одинаковую длительность, даже если роль
  оказалась в центре. Этап не заканчивается раньше из-за быстрого действия:
  так таймер не раскрывает скрытую информацию.
- Необязательный ночной ход по таймеру пропускается.
- Пьяница обязан обменяться: по таймеру сервер случайно выбирает одну карту центра.
- Голос не был подан до конца таймера — игрок воздержался; случайный голос не ставится.
  Это отличие от настольной игры, где все голосуют одновременно. Если охотник
  воздержался, у него нет цели для выстрела.
- Выход со страницы не удаляет игрока. Его карта остаётся, а таймеры идут дальше.
- Создатель может отменить сорванный раунд и удалить отсутствующего участника в лобби.
  Если создатель отсутствует 45 секунд, другому игроку доступна передача управления.

## 7. Переподключение и личный ключ

- Обычное обновление страницы сохраняет игрока: сессия находится в `sessionStorage`.
- При временном обрыве сеть проверяется автоматически раз в секунду.
- Кнопка **«Личный ключ»** позволяет сохранить токен входа. Запишите его вместе
  с кодом лобби: он нужен при закрытии вкладки, смене браузера или адреса сервера.
- Для восстановления откройте главную страницу и раздел
  **«Восстановить вход по личному ключу»**. Укажите код и ключ.
- **Не отправляйте личный ключ друзьям**: он даёт управление вашим игроком
  и доступ к вашей скрытой информации. Для приглашения есть отдельная ссылка.
- Разные игроки используют отдельные устройства или независимо открытые вкладки.
  Не дублируйте вкладку с уже открытой игрой: браузер может скопировать её сессию.

## 8. Проверка проекта

Из папки проекта:

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

Linux/macOS:

```bash
.venv/bin/python -m unittest discover -s tests -v
```

В комплекте 80 тестов. Они не требуют дополнительных Python-пакетов и проверяют роли, порядок
обменов, исходы голосования, таймеры, права создателя, изоляцию комнат,
закрытые ответы API и общую музыку. Внутри теста случайных раундов проходят 96 полных партий
с разным числом игроков. `/health` возвращает `{"status":"ok"}`.

Для ручной проверки на одном ПК откройте **три новые независимые вкладки**,
в каждой вручную перейдите на адрес сервера, создайте лобби и войдите с разными
именами. Лучше использовать отдельные профили браузера. После проверки
подключите телефон по LAN — это проверит ещё и настройки сети.

Python отвечает за **всю игровую логику** и хранение секретов. HTML/CSS/JavaScript
нужны только для интерфейса браузера. Установка приложения на телефоны не требуется.
Клиент регулярно получает персональный JSON. Текущие скрытые карты игроков и центра,
чужие заметки и чужие выборы голосования до финала в него не входят. Ночные
наблюдения передаются только действующему игроку как снимки разрешённых ему карт
на момент действия; текущие роли после чужих обменов по ним получить нельзя. Создатель лобби не получает
расширенный доступ к скрытым данным. Владелец машины с сервером, как и в любой
локально размещённой игре, технически может прочитать память сервера.

Изменения состояния защищены блокировкой. Ночные действия разрешаются по серверной
фазе и исходной роли, а не по данным клиента. Запросы устаревшей фазы отклоняются.
Токены передаются в заголовке `Authorization`, не в ссылках. Внешних шрифтов,
изображений, аналитики и JavaScript-библиотек интерфейс не загружает.

## 10. Ограничения и решение проблем

### Обновление до версии с общей музыкой

1. Завершите текущую партию и остановите сервер игры (Ctrl+C).
2. Распакуйте архив и скопируйте содержимое папки `one_night_werewolf` в свою
   папку проекта **с заменой файлов**. Папки `.venv` и свои музыкальные файлы
   удалять не нужно. Пустой шаблон `music` содержит только инструкцию.
3. Запустите привычный `start_windows.bat` и используемый вами способ подключения.
4. Обновите страницу игры у всех участников (при необходимости Ctrl+F5).
   После перезапуска сервера создайте новое лобби.

Python 3.9 поддерживается. Для чтения длительности музыки добавлен Mutagen 1.47.0.
Скрипт запуска сам установит его из папки `wheels` при первом запуске после обновления.
Все зависимости входят в архив: интернет для их установки не нужен.


### Ошибка pip: `check_hostname requires server_hostname`

Если в трассировке есть `_prepare_proxy` и `_connect_tls_proxy`, сбой происходит
при HTTPS-подключении установщика через прокси. В этой версии запуск больше
не требует обращения к PyPI: все необходимые пакеты находятся в папке `wheels`.

1. Распакуйте **весь новый архив** с заменой файлов в свою папку проекта,
   включая `wheels`, `requirements-offline.txt` и `install_dependencies.py`.
2. Сохраните свою папку `music`. Удалять `.venv` или переустанавливать Python не нужно.
3. Запустите `start_windows.bat`. При отсутствии зависимостей он установит их локально.

Для ручного восстановления зависимостей в PowerShell из папки проекта:

```powershell
.\.venv\Scripts\python.exe install_dependencies.py
.\.venv\Scripts\python.exe app.py
```

Установщик проверяет целостность локальных пакетов по SHA-256. Настройки pip
и прокси игнорируются только для процесса установки; настройки Windows,
VPN, переменные среды пользователя и сертификаты не изменяются.
Если уже установленные Flask, Waitress и Mutagen успешно импортируются, обычный запуск
вообще пропускает установку пакетов. Интернет всё ещё нужен для игры с друзьями
через интернет; это исправление относится к установке зависимостей.

### Обновление с первой версии архива

Если запуск завершался ошибкой `TypeError: unsupported operand type(s) for |`,
обновите файлы из этого архива с заменой. В игровой логике запись `str | None`
заменена совместимой с Python 3.9 записью `Optional[str]` (аналогично для остальных
полей). При установленном Python 3.9 переустановка Python и удаление `.venv` не нужны.

Скрипты запуска теперь проверяют версию и выводят её перед запуском. Проверить
версию именно игрового окружения в PowerShell можно командой:

```powershell
.\.venv\Scripts\python.exe --version
```

Если окружение использует Python ниже 3.9, установите подходящий Python,
удалите **только папку `.venv` внутри проекта** и снова запустите
`start_windows.bat`: он создаст окружение заново. Установка нового Python сама
по себе не обновляет интерпретатор уже существующей `.venv`.


- **Перезапуск сервера очищает все комнаты.** Неактивное лобби хранится до шести
  часов и убирается при следующем создании комнаты. Сохранений партий на диск нет.
- **Нет голосового чата и ботов.** Есть общий текстовый чат и игра живыми участниками.
- **Порт занят:** запустите `python app.py --port 8001`; затем в браузере и команде
  туннеля тоже используйте `8001`.
- **Друзья не видят сервер:** проверьте адрес ПК, порт, брандмауэр, одну сеть
  и отсутствие изоляции клиентов. `0.0.0.0` — адрес привязки сервера, не ссылка для браузера.
- **Лобби не найдено:** проверьте, что все открыли один сервер. После его
  перезапуска нужно создать новую комнату.
- **Имя уже занято:** восстановите старый вход по ключу либо попросите создателя
  удалить старого участника в лобби.
- **Кнопка старта неактивна:** нужно минимум три игрока и подтверждение от каждого.
- **После присоединения друга своя колода перестала подходить:** добавьте карту
  вручную или сохраните настройки с автоподбором.
- **Скопировать приглашение не получилось:** на обычном HTTP браузер может
  запрещать Clipboard API. Появится окно, из которого можно скопировать ссылку вручную.
- **Сервер недоступен по интернету:** убедитесь, что оба окна запущены и публичная
  ссылка не устарела. Quick Tunnel — внешний сервис, его работоспособность зависит от сети.

При игре с телефонов держите вкладку открытой, особенно ночью: мобильные браузеры
могут замедлять фоновые вкладки. При возврате сервер пришлёт актуальную фазу.

## Обновление: общий счёт и выбывшие игроки

После завершения каждого раунда сервер начисляет очки по **конечной роли**:
- каждому победившему мирному — 1 очко;
- каждому оборотню и миньону (приспешнику) при победе их команды — 2 очка;
- победившему кожевнику — 3 очка.

При совместной победе деревни и кожевника очки получают обе победившие стороны.
Если никто не победил, начислений нет. Повторные запросы не начисляют очки повторно.
Отмена незавершённого раунда не даёт очков.

Гистограмма показана в лобби и в результатах; кнопка **«Счёт»** в верхней панели
открывает её в любой фазе. Обновление у всех игроков — через существующий опрос
сервера примерно раз в секунду. Столбцы анимированы; рядом указаны общий счёт
и прибавка за последний завершённый раунд.

Счёт сохраняется при переходе к следующему раунду и восстановлении той же сессии.
Он хранится в памяти сервера, как и лобби: перезапуск сервера удаляет лобби и счёт.
Новый участник начинает с нуля; выход/исключение удаляет участника вместе с его счётом.

Выбывшие по голосованию и жертва охотника отмечены красным крестом на всю карту.
При ничьей крестом отмечены все выбывшие. Оранжевое выделение личного голоса
показывается только во время голосования и убирается в результатах.

### Доступ друзьям через Pinggy

Запустите игру обычным способом (`start_windows.bat` на Windows, `bash start.sh`
на Linux/macOS). Пока сервер работает на порту 8000, откройте второй терминал:

```sh
ssh -p 443 -R0:127.0.0.1:8000 free.pinggy.io
```

Отправьте друзьям HTTPS-ссылку, которую покажет Pinggy, и код лобби.
Оба окна должны оставаться открытыми. Если запрошен пароль, нажмите Enter.
Документация: https://pinggy.io/docs/

## Обновление интерфейса от 29.10.2026

- Полноэкранное уведомление **«Ваш ход!»** появляется при наступлении ночного
  этапа вашей начальной роли, включая роли без ручного действия. Отдельные
  уведомления обозначают знакомство с картой и начало голосования. На экране
  есть оставшееся время и кнопка перехода к столу. Таймер сервера не останавливается.
  Повторные запросы и перезагрузка вкладки не повторяют уже показанное уведомление
  текущего этапа. При смене этапа уведомление закрывается автоматически.
- Полоски счёта теперь обновляются через JavaScript без заблокированных политикой
  безопасности HTML-стилей. Ширина равна `очки игрока / максимальный счёт × 100%`:
  например, 1, 2 и 4 очка отображаются как 25%, 50% и 100%. Нулю соответствует
  пустая полоска. При начислении анимируются и длина, и число очков; при смене
  максимального счёта пересчитывается вся шкала. Одинаковые ответы сервера
  не перезапускают анимацию. Настройка системы «уменьшение движения» учитывается.
- Подтверждения голосования, исключения игрока, выхода, отмены раунда и начала
  голосования оформлены встроенными окнами. Отмена, Escape, крестик и нажатие
  вне окна не отправляют команду. Если фаза или выбранный участник изменились,
  устаревшее подтверждение закрывается. Личный ключ и резервное ручное копирование
  также показываются в интерфейсе игры вместо браузерного `prompt`.

## Освещение и анимированная деревня

Над столом добавлен пейзаж с деревней, лесом и небом. Фон всей страницы,
освещение стола и панелей согласованы с общей фазой игры:

| Фаза | Окружение |
| --- | --- |
| Лобби | Закат, тёплые окна, горящие свечи |
| Знакомство с ролью | Сумерки, появление луны и первых звёзд |
| Ночь | Луна, звёзды, холодный свет; свечи и окна темнеют |
| Обсуждение | Предрассветное небо, низкое солнце и лёгкий туман |
| Голосование | Приглушённое солнце за облаками, сдержанные медные оттенки |
| Результаты | Солнце поднимается, появляется тёплый утренний свет |

Слои неба плавно сменяются, небесные тела поднимаются и опускаются,
облака и туман движутся, свечи мягко колеблются. Освещение зависит только
от публичной фазы — не от тайных ролей, действий или победителей.
Опрос сервера не пересоздаёт пейзаж и не перезапускает анимации.

Кнопка **«Анимация: вкл./выкл.»** на пейзаже сохраняет личный выбор на устройстве.
При выключении цвета и небесные тела продолжают соответствовать текущей фазе,
но переходы и постоянное движение отключены. Системная настройка уменьшения
движения имеет приоритет. В фоновой вкладке постоянные анимации приостановлены.

Пейзаж создан средствами CSS/SVG, работает без внешних ресурсов, дополнительных
пакетов и загрузки изображений. Новые эффекты не меняют правила и таймеры.

### План звуков (аудио ещё не подключено)

По согласованному варианту короткий звук роли будет слышен **всем** в начале её
ночного этапа, даже если эта карта находится в центре. Звук обозначает этап,
а не присутствие игрока с ролью. Никакие реальные ночные действия не должны
добавлять внеплановые общие звуки. Подробный список файлов — в SOUNDS_PLAN.md.
